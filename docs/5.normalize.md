# 5. Normalize

`scripts/5.normalize.py`

Normalizes each plate's guide-level and gene-level profiles with Pycytominer.
If `output_bygene` is `true`, each plate's single cells are also normalized in the same way and written one file per gene and per guide.
Columns that are all 0 are dropped, and location columns are not normalized.
Normalization statistics are calculated from the samples in `by_samples` (by default the `control_genes`).

## Inputs

| Input | Description |
| --- | --- |
| `profiles/{plate}_{data_set_name}_{gene\|guide}.csv.gz` | From [step 4](4.aggregate.md) |
| `single_cell/by_site/{plate}-{well}-{site}/*_single_cell.csv.gz` or `single_cell/{plate}_single_cell_{data_set_name}.csv.gz` | From [step 2](2.merge-single-cells.md), only if `output_bygene` is `true` |

Config used: `data_sets`, `control_genes` (experiment); `normalize.*`, `process_SBS.gene_col`, `process_SBS.barcode_col`, `single_cell.save_single_file`, `core.*` (defaults). See [Configuration](configs.md).

## Outputs

| Output | Description |
| --- | --- |
| `profiles/{plate}_{data_set_name}_{gene\|guide}_normalized.csv.gz` | Normalized profiles |
| `single_cell/single_cell_by_gene/{data_set_name}_gene_normalized_{gene}.csv.gz` | Normalized single cells (one row per cell, with `Metadata_Well` and `Metadata_Site`) split into one file per gene (only if `output_bygene` is `true`) |
| `single_cell/single_cell_by_gene/{data_set_name}_guide_normalized_{barcode}.csv.gz` | The same, split into one file per guide barcode |

If no samples match `by_samples` for a plate (e.g. no control gene is present), a warning is logged and that plate is not normalized.
