# 7. Explore

`scripts/7.explore.py`

Performs preliminary exploration of the biological relationships in the final profiles: a UMAP embedding with controls highlighted, a heatmap, a mean average precision (mAP) test of whether replicates of a gene are distinguishable from the negative controls (using [copairs](https://github.com/cytomining/copairs)) (phenotypic activity), a similar metric of whether replicates are distinguishable from other treatments (phenotypic distinctiveness), and similarity to positive controls.

It also generates radar plots for each gene and guide, showing changes from control at various percentiles across compartments, channels, and feature categories.

Does not respect `overwrite_files`.

## Inputs

| Input | Description |
| --- | --- |
| `profiles/{plate}_{data_set_name}_{gene\|guide}_normalized_feature_selected_by{group}.csv.gz` | From [step 6](6.feature-select.md) |

Config used: `data_sets`, `control_genes`, `poscon_genes` (experiment); `feature_select.group`, `process_SBS.gene_col`, `process_SBS.barcode_col` (defaults). See [Configuration](configs.md).

## Outputs

All in `data_exploration/`.

| Output | Description |
| --- | --- |
| `{plate}_{data_set_name}_{gene\|guide}_normalized_{group}_UMAP.png` | UMAP of each gene/guide, colored by gene, with controls (hexagons) and positive controls (stars) marked. |
| `{plate}_{data_set_name}_{gene\|guide}_normalized_{group}_heatmap.png` | Heatmap of profiles by gene (gene-level) or gene and guide (guide-level) |
| `{plate}_{data_set_name}_guide_normalized_{group}_feature_selected_mAP_activity.csv.gz` | mAP and corrected p-value per gene, compared to negative controls |
| `{plate}_{data_set_name}_guide_normalized_{group}_feature_selected_mAP_activity_scatterplot.png` | mAP vs. -log10(p-value), positive controls marked |
| `{plate}_{data_set_name}_guide_normalized_{group}_feature_selected_mAP_distinctiveness.csv.gz` | mAP and corrected p-value per gene, compared to other treatments |
| `{plate}_{data_set_name}_guide_normalized_{group}_feature_selected_mAP_distinctiveness_scatterplot.png` | mAP vs. -log10(p-value), positive controls marked |
| `{plate}_{data_set_name}_{gene\|guide}_normalized_{group}_feature_selected_{gene}_cosine_similarity.csv` | Cosine similarity of each profile to the positive control `{gene}` (only if `poscon_genes` is set) |
| `gene_radar_plots/{data_set_name}/{plate}/{gene}_radar.png` | Radar plots at the gene level |
| `guide_radar_plots/{data_set_name}/{plate}/{gene}_{guide}_radar.png` | Radar plots at the guide level |

The mAP is calculated on the guide-level profiles of each plate.

Note that if you have only a few "dimensions" of biology in your experiment and many examples of each, phenotypic distinctiveness may seem low even when phenotypic activity is high - as an example, if your experiment has only a negcon, four compounds that cause G1 arrest, and four compounds that cause G2 arrest, even if all eight compounds are perfectly separable from negative control, if the closest replicate well to G1-disruptor-1 is a well which contains G1-disruptor-2, distinctiveness will mark this as an incorrect match even though the wells "should" look alike, biologically. If you have a metadata column that describes these known relationships (such as a `Metadata_Target` column), you can run `copairs` on your generated profiles for *phenotypic consistency* - see that library for more information.
